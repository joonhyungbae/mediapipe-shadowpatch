# 작은 화면에 올리는 세 가지 길

이 페이지는 브라우저에서 돕니다. 그래서 무엇에 올리든 코드는 그대로이고, 카메라와 화면과 전원만 달라집니다.
아래 셋은 **실험하기 쉬운 순서** 입니다. 앞에서 규칙을 정하고, 뒤로 갈수록 전시 장비에 가까워집니다.

어느 길이든 먼저 정할 것이 하나 있습니다. **색면을 보는 사람이 누구인가** 입니다.
카메라 앞에 선 사람이 보는지, 그 사람을 바라보는 다른 관객이 보는지에 따라 화면이 향하는 쪽이 바뀝니다.

## 1. 노트북 그대로 (규칙을 찾는 동안)

| 역할 | 무엇으로 |
|---|---|
| 카메라 | 노트북 카메라, 또는 USB 웹캠을 원하는 자리에 두고 긴 USB 선으로 잇는다 |
| 연산 | 노트북 |
| 화면 | 노트북 화면, 또는 USB-C 로 꽂는 휴대용 모니터 |
| 전원 | 노트북 |

- 사는 것 없이 바로 시작할 수 있습니다.
- USB 웹캠을 꽂으면 화면 오른쪽 「무엇을 보나」에 카메라 이름이 하나 더 뜹니다.
- 바깥을 향한 카메라로 남을 찍을 때는 조절판의 「거울처럼 뒤집기」를 끕니다.

## 2. 스마트폰 하나 (카메라 · 연산 · 화면이 한 덩어리)

| 역할 | 무엇으로 |
|---|---|
| 카메라 · 연산 · 화면 | 스마트폰 한 대 |
| 전원 | 폰 배터리. 오래 돌리려면 보조배터리나 충전기를 같이 단다 |

- 폰 브라우저에서 이 페이지를 엽니다. 폰은 `localhost` 가 아니라서 **https 주소** 가 필요합니다.
  `https://joonhyungbae.github.io/mediapipe-shadowpatch/?display` 가 그 주소입니다.
  자기 규칙으로 고친 판을 폰에서 열려면 자기 GitHub 저장소에서 Pages 를 켭니다.
- **카메라 방향과 화면 방향이 엇갈립니다.** 뒤 카메라로 찍으면 화면은 반대쪽을 봅니다. 앞(셀피) 카메라로
  찍으면 화면이 찍히는 사람 쪽을 봅니다. 위에서 정한 「누가 보나」로 고릅니다.
- 화면이 저절로 꺼지지 않게 막아 두었습니다(되는 브라우저에서만). 폰 설정의 자동 잠금도 꺼 둡니다.
- 폰마다 빠르기가 다릅니다. 화면 아래 fps 숫자로 확인합니다.

## 3. 라즈베리파이 5 + 카메라 + 작은 화면 (전용 장비)

| 역할 | 무엇으로 |
|---|---|
| 카메라 | USB 웹캠 (라즈베리파이 전용 카메라 모듈은 브라우저에서 쓰려면 설정이 더 필요해 USB 쪽이 쉽다) |
| 연산 | 라즈베리파이 5, 크로미움 브라우저로 이 페이지를 연다 |
| 화면 | HDMI 나 DSI 로 꽂는 5~7인치 작은 화면 |
| 전원 | 어댑터, 또는 USB-C PD 보조배터리 |

- 설치부터 자동 시작까지는 [raspberrypi.md](raspberrypi.md) 의 순서를 따릅니다. `scripts/pi-setup.sh` 하나로
  프로그램 설치, 모델 받기, 켜면 바로 뜨기까지 끝납니다.
- **재 봐야 할 것 셋** 은 직접 실험으로 확인합니다. 이 저장소에서는 아직 재지 않았습니다.
  `scripts/pi-check.sh` 가 온도와 전원 상태를 적어 줍니다.
  - 빠르기: 화면 아래 fps. 너무 느리면 주소에 `in=256` 처럼 붙여 줄입니다.
  - 전원: 라즈베리파이 5 는 전원이 넉넉해야 USB 장치를 제대로 돌립니다. 보조배터리로 쓴다면 몇 시간 가는지,
    카메라가 끊기지 않는지 켜 두고 잽니다.
  - 열: 한 시간 켜 두고 만져 봅니다. 뜨거우면 쿨러를 답니다. 케이스 안에 넣거나 몸에 닿는 곳이면 더 중요합니다.

## 무엇을 고르든 전시 전에 볼 것

- 하루 동안 켜 둘 때 전원은 어디서 오는가. 배터리라면 몇 번 갈아야 하는가.
- 선이 사람에게 걸리지 않는가. 카메라 방향이 틀어지지 않게 고정됐는가.
- 화면이 꺼지거나 페이지가 멈추면 누가 다시 켜는가.
