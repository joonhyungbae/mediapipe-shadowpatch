# sample · 카메라 대신 쓸 영상

웹캠이 없거나, 같은 움직임으로 규칙을 여러 번 비교해 보고 싶을 때 씁니다.

```bash
./start.sh --video sample/팔벌려뛰기.webm
```

화면 오른쪽 「무엇을 보나」에서 **영상 파일 열기** 를 골라도 됩니다.

영상은 저장소에 올라가지 않습니다. 설치할 때 받고, 따로 받으려면 `python3 fetch_model.py --sample` 입니다.
받을 때 출처와 조건이 `credits.md` 에 적힙니다.

- `팔벌려뛰기.webm` 한 사람이 팔 벌려 뛰기와 버피를 합니다(45초). 팔을 벌렸다 모으고, 웅크렸다
  일어서고, 옆으로 돌아서는 동작이 다 있어 숫자 막대가 고르게 움직입니다.
  위키미디어 공용, Taco fleur, CC BY-SA 4.0. 시험용으로만 씁니다.

자기 영상도 됩니다. 사람의 상반신이나 온몸이 화면에 들어오는 영상이 잘 잡힙니다. 카메라를 둘
자리에서 휴대폰으로 미리 찍어 두면 전시장과 비슷한 조건으로 규칙을 맞춰 볼 수 있습니다.
